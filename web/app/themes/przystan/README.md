# Motyw „Przystań Brda”

Motyw strony demonstracyjnej na bazie [Sage 11](https://roots.io/sage/) (Blade, Tailwind CSS 4, Vite).
Odpowiada tylko za wygląd: dane, logika i tłumaczenia są we wtyczce `przystan-core`.
Opis całego projektu, uruchomienie i decyzje: [README w katalogu głównym](../../../../README.md).
